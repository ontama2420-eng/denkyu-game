# 電球くん

タブレットのブラウザで遊ぶ、動画を使ったゲームです。room1では電球の光、時計、ジョウロ、ドアをタップして先へ進みます。

## 起動と操作

1. ZIPを展開し、PCのChromeやEdgeで `denkyu-game/index.html` を開きます。
2. タブレットで遊ぶ場合は、`denkyu-game` の中身を静的Webサーバーで配信し、タブレットのブラウザで開きます。PCでPythonが使える場合は、このフォルダで `python -m http.server 8000` を実行すると、PCからは `http://localhost:8000/` で確認できます。同じネットワークのタブレットからは `http://<PCのIPアドレス>:8000/` を開きます。
3. **START** を押します。電球の光、時計、ジョウロ、ドアの場面では、対象がタップされるまで動画をループします。ジョウロは画面左側にあります。対象をタップすると次の動画を再生し、次の映像が表示できるまで直前のフレームを表示します。
4. ほかの動画は再生が終わると自動で進みます。最後に「おしまい」が表示され、「もう一度遊ぶ」でroom1を再開できます。

## 動画と進行

素材は `videos/room1/` に入っています。元のZIPにあったファイル名を使っています。

## タップ位置の調整

配信URLの末尾に `?debug=1` を付けるか、PCで `D` キーを押すと、動画ID、タップ範囲、指やマウスの座標が表示されます。点線は有効なタップ範囲です。

`rooms.js` の `hit: [x, y, 幅, 高さ]` を調整します。座標の原点は動画が表示される領域の左上で、右にx、下にyが増えます。2728×2048の基準座標を使うため、端末の画面サイズに合わせて数値を変更する必要はありません。

## room2と音声の追加

- 動画を `videos/room2/` に入れ、`rooms.js` の `ROOMS` に `room2` を登録します。`directory` と、再生順に並べた `clips` を設定します。タップで進む動画には `hit` と `label` を付けます。room1の `next` は `room2` を指しているので、登録後はroom1の終了時にroom2へ進みます。
- 部屋の `videoSound` を `true` にすると、MP4に入っている音声を再生します。BGMは `music` に音声ファイルのパスを設定すると部屋の間ループします。端末の自動再生制限があるため、音声を追加したら対象端末で確認してください。現在のroom1はミュートで、BGMは未設定です。
